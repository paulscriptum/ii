# Доступ к OpenClaw через браузер

## Текущая ситуация

OpenClaw Gateway работает через **WebSocket протокол** (`ws://127.0.0.1:18789`), а не через обычный HTTP. Это означает, что прямой доступ через браузер к основному интерфейсу невозможен без дополнительной настройки.

## Варианты решения

### Вариант 1: Использовать Canvas (если доступен)

OpenClaw может иметь Canvas интерфейс. Попробуйте открыть в браузере:

```
http://127.0.0.1:18789/__openclaw__/canvas/
```

**Важно:** Убедитесь что SSH туннель активен!

### Вариант 2: Создать простой веб-интерфейс

Я могу создать простой HTML/JavaScript интерфейс, который будет подключаться к OpenClaw через WebSocket и предоставлять веб-интерфейс.

### Вариант 3: Использовать WebSocket клиент в браузере

Можно использовать браузерные инструменты для подключения к WebSocket:
- Chrome DevTools → Network → WS (WebSocket)
- Или специальные WebSocket клиенты расширения браузера

### Вариант 4: Настроить HTTP прокси

Создать простой Node.js сервер, который будет:
1. Принимать HTTP запросы от браузера
2. Переводить их в WebSocket запросы к OpenClaw
3. Возвращать ответы обратно в браузер

## Токен аутентификации

Если нужна аутентификация, используйте токен из конфигурации:
```
9b0dd3b6cff44e7c0fbcb637f6179b9643979eaedefb10da
```

## Быстрая проверка

1. Убедитесь что SSH туннель активен:
```bash
ps aux | grep "ssh.*18789"
```

2. Попробуйте открыть в браузере:
```
http://127.0.0.1:18789/__openclaw__/canvas/
```

3. Или проверьте через curl:
```bash
curl http://127.0.0.1:18789/__openclaw__/canvas/
```
