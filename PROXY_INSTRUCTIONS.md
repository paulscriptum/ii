# Инструкция по использованию прокси для OpenClaw

## ✅ Прокси сервер создан и готов к использованию!

Я создал прокси сервер, который решает проблему подключения через браузер.

## Как использовать:

### Шаг 1: Убедитесь что SSH туннель активен

В Терминале выполните (если еще не запущен):

```bash
ssh -L 18789:127.0.0.1:18789 root@217.25.94.44
```

Введите пароль: `eQR^o3^3WkG4Ki`

**Оставьте это окно открытым!**

### Шаг 2: Запустите прокси сервер

Откройте **НОВОЕ** окно Терминала и выполните:

```bash
cd /Users/pavelshchepochkin/ii
node openclaw-proxy.js
```

Или используйте скрипт:

```bash
cd /Users/pavelshchepochkin/ii
./start-proxy.sh
```

Вы увидите:
```
OpenClaw Proxy Server running on http://127.0.0.1:8080
OpenClaw Gateway: ws://127.0.0.1:18789
Open http://127.0.0.1:8080 in your browser
```

**Оставьте это окно тоже открытым!**

### Шаг 3: Откройте браузер

Откройте в браузере:

```
http://127.0.0.1:8080
```

### Шаг 4: Подключитесь

1. Нажмите кнопку **"Подключиться"**
2. Статус должен измениться на "Подключено" (зеленый)
3. Введите сообщение и нажмите "Отправить"

## Что делает прокси:

- ✅ Принимает WebSocket соединения от браузера на порту 8080
- ✅ Пересылает их в OpenClaw Gateway на порту 18789
- ✅ Передает сообщения в обе стороны
- ✅ Обрабатывает ошибки и переподключения

## Файлы:

- `openclaw-proxy.js` - прокси сервер
- `start-proxy.sh` - скрипт для запуска
- `openclaw-web.html` - веб-интерфейс (обновлен)

## Остановка прокси:

Нажмите `Ctrl + C` в окне где запущен прокси сервер.

## Устранение проблем:

### "Cannot find module 'ws'"
```bash
cd /Users/pavelshchepochkin/ii
npm install ws
```

### "Port 8080 already in use"
Измените порт в файле `openclaw-proxy.js`:
```javascript
const PROXY_PORT = 8081; // или другой свободный порт
```

### Прокси не подключается к Gateway
- Проверьте что SSH туннель активен
- Проверьте что контейнер OpenClaw запущен: `ssh root@217.25.94.44 'docker ps | grep openclaw'`
