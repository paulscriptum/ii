# Пошаговая инструкция для MacBook - Подключение к OpenClaw

## Шаг 1: Открыть Терминал на Mac

1. Нажмите `Cmd + Пробел` (Command + Space)
2. Введите "Terminal" и нажмите Enter
3. Или найдите Терминал в папке "Программы" → "Утилиты"

---

## Шаг 2: Подключиться к серверу по SSH

Введите эту команду и нажмите Enter:

```bash
ssh root@217.25.94.44
```

**Что произойдет:**
- Вас спросят "Are you sure you want to continue connecting?" - введите `yes` и нажмите Enter
- Затем попросит пароль - введите: `eQR^o3^3WkG4Ki` (пароль не будет виден при вводе - это нормально)
- Нажмите Enter

**Если подключились успешно**, увидите что-то вроде:
```
root@ваш-сервер:~#
```

---

## Шаг 3: Проверить статус OpenClaw

После подключения выполните команды по очереди:

### 3.1. Проверить что контейнер работает:
```bash
docker ps | grep openclaw
```

**Должно показать:** что-то вроде `openclaw-gateway` со статусом "Up"

### 3.2. Проверить логи (последние 20 строк):
```bash
docker logs --tail 20 openclaw-gateway
```

**Что искать:** строки типа:
- `[gateway] listening on ws://127.0.0.1:18789`
- `[browser/service] Browser control service ready`

### 3.3. Проверить что OPENCLAW_STATE_DIR установлена:
```bash
docker exec openclaw-gateway sh -c "echo OPENCLAW_STATE_DIR=\${OPENCLAW_STATE_DIR}"
```

**Должно показать:** `OPENCLAW_STATE_DIR=/home/node/.openclaw`

---

## Шаг 4: Настроить SSH туннель (для доступа к OpenClaw)

### Вариант A: В новом окне Терминала на Mac

1. Откройте **НОВОЕ** окно Терминала (Cmd+T или Cmd+N)
2. В новом окне выполните:

```bash
ssh -L 18789:127.0.0.1:18789 root@217.25.94.44
```

3. Введите пароль: `eQR^o3^3WkG4Ki`
4. **Оставьте это окно открытым** - оно создает туннель

### Вариант B: В фоновом режиме (более удобно)

В новом окне Терминала выполните:

```bash
ssh -f -N -L 18789:127.0.0.1:18789 root@217.25.94.44
```

Введите пароль, и туннель будет работать в фоне.

---

## Шаг 5: Проверить что туннель работает

В новом окне Терминала (или в том же, если использовали вариант B) выполните:

```bash
curl http://127.0.0.1:18789/
```

**Результат:** Может быть пустой ответ или ошибка - это нормально, главное что порт отвечает.

---

## Шаг 6: Подключиться к OpenClaw через TUI

Теперь можно подключиться к OpenClaw через TUI (если у вас установлен клиент OpenClaw):

```bash
openclaw connect ws://127.0.0.1:18789
```

Или используйте токен из конфигурации (если нужен).

## Полезные команды для проверки

### Посмотреть все логи OpenClaw:
```bash
docker logs openclaw-gateway
```

### Посмотреть логи в реальном времени:
```bash
docker logs -f openclaw-gateway
```
(Нажмите Ctrl+C чтобы выйти)

### Перезапустить контейнер:
```bash
cd /root
docker compose restart openclaw-gateway
```

### Остановить контейнер:
```bash
cd /root
docker compose stop openclaw-gateway
```

### Запустить контейнер:
```bash
cd /root
docker compose start openclaw-gateway
```

## Если что-то пошло не так

### Проблема: "Connection refused" при SSH
- Проверьте интернет соединение
- Убедитесь что IP адрес правильный: `217.25.94.44`

### Проблема: "Permission denied" при SSH
- Проверьте что пароль правильный: `eQR^o3^3WkG4Ki`
- Убедитесь что вводите `root` (не `admin` или другое)

### Проблема: "docker: command not found"
- Это значит вы не на сервере, а на своем Mac
- Убедитесь что выполнили `ssh root@217.25.94.44` сначала

### Проблема: Контейнер не запущен
```bash
cd /root
docker compose up -d
```

### Проблема: Ошибка device token mismatch все еще есть
```bash
# Проверить логи на ошибки
docker logs openclaw-gateway | grep -i "token\|mismatch\|error"

# Перезапустить контейнер
cd /root
docker compose restart openclaw-gateway
```

## Выход из SSH

Когда закончите работу, выйдите из SSH:
```bash
exit
```

Или нажмите `Ctrl+D`

---

## Важные замечания

1. **SSH туннель должен быть активен** пока вы используете OpenClaw
2. Если закрыли окно с туннелем - создайте его заново
3. Пароль: `eQR^o3^3WkG4Ki` (обратите внимание на символы `^`)
4. Все команды с `docker` выполняются **на сервере** (после `ssh root@...`)
