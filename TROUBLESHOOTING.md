# Устранение проблемы "socket hang up"

## Проблема
После успешного подключения к прокси происходит ошибка "socket hang up" и соединение с Gateway обрывается.

## Что было исправлено

1. ✅ Улучшена обработка ошибок подключения
2. ✅ Добавлено логирование для отладки
3. ✅ Добавлена проверка состояния соединений
4. ✅ Улучшена обработка закрытия соединений

## Диагностика

### Проверьте логи прокси:
```bash
tail -f /tmp/openclaw-proxy.log
```

### Проверьте логи Gateway:
```bash
ssh root@217.25.94.44 'docker logs -f openclaw-gateway'
```

### Проверьте SSH туннель:
```bash
ps aux | grep "ssh.*18789"
```

## Возможные причины

1. **Gateway требует специфический протокол**
   - OpenClaw Gateway может требовать определенный формат сообщений
   - Возможно нужна аутентификация перед отправкой сообщений

2. **Проблема с SSH туннелем**
   - Туннель может обрываться
   - Проверьте что туннель стабилен

3. **Gateway закрывает соединение**
   - Gateway может закрывать соединения без активности
   - Нужно отправлять heartbeat сообщения

## Решения

### Вариант 1: Проверьте формат сообщений

OpenClaw Gateway может требовать специфический формат. Попробуйте отправить сообщение в формате:

```json
{
  "type": "chat",
  "message": "ваше сообщение"
}
```

### Вариант 2: Добавьте heartbeat

Gateway может требовать периодические сообщения для поддержания соединения.

### Вариант 3: Проверьте аутентификацию

Возможно Gateway требует аутентификацию перед использованием. Проверьте токен в конфигурации.

## Следующие шаги

1. Откройте браузер: http://127.0.0.1:8080
2. Подключитесь
3. Следите за логами прокси: `tail -f /tmp/openclaw-proxy.log`
4. Попробуйте отправить сообщение
5. Проверьте что происходит в логах

Если проблема сохраняется, пришлите логи из `/tmp/openclaw-proxy.log` и логи Gateway.
